1 · Colle ta réservation Booking

  1. Ouvre la réservation sur l'extranet Booking.
  2. Clic droit → « Afficher le code source » (ou Ctrl + U).
  3. Ctrl + A puis Ctrl + C pour tout copier.
  4. Colle ci-dessous, puis clique « Extraire ».

2 · Vérifie / corrige

💡 Le plus simple : clique « Copier pour Claude » puis colle le message dans le chat — je publie en quelques secondes.
